### [skillkit](https://github.com/maxvaega/skillkit) — 137 ⭐
> Enable Anthropic's Agent Skills in any Python agent

Lets LLM-powered agents autonomously discover and load modular skill packages — a token-efficient alternative to bloated system prompts. Published on PyPI, compatible with LangChain and framework-free deployments.
